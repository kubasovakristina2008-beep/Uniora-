# Uniora

Персональный маршрут поступления в зарубежный вуз — проект для **LOCUS Startup Hackathon 2026**, кейс 02 «Персональный маршрут поступления».

## Задача

Абитуриенты, рассматривающие поступление за рубежом, обычно сталкиваются с разрозненной информацией об общем каталоге вузов вместо персонального плана: требования по экзаменам раскиданы по десяткам сайтов, непонятно, какие вузы реально соответствуют профилю, а какие — амбициозная ставка, и нет пошагового плана до дедлайнов подачи. Кейс 02 — построить продукт, который превращает анкету конкретного абитуриента в персональный, понятный и честный маршрут поступления.

## Решение

Uniora ведёт пользователя по цепочке из шести экранов:

1. **Анкета** (6 шагов) — класс/этап обучения, специальность (или мини-квиз на 5 вопросов, если ещё не определился), страны, достижения (7 категорий записей + спорт + волонтёрство), экзамены (IELTS/TOEFL/SAT/GPA слайдерами с честным тумблером «ещё не сдавал(а)»).
2. **Диагностика** — честный портрет абитуриента: радар-диаграмма по 4 реальным сигналам (английский, SAT, GPA, документы), сильные стороны, точки роста, рекомендованный фокус на неделю.
3. **Рекомендации** — вузы по категориям Match / Reach / Safety с человекочитаемым объяснением «почему», симулятор «что если» (подвинуть баллы и увидеть, что изменится).
4. **Сравнение** — до 3 вузов рядом, построчно.
5. **Roadmap** — 9 шагов до зачисления, первые 5 синхронизируются автоматически из анкеты, плюс пользователь может добавлять свои цели/дедлайны, чек-лист документов с мини-гайдами (как писать мотивационное письмо, где брать рекомендательные письма и искать научного руководителя через LinkedIn).
6. **Избранное** и **сравнение приоритетов по странам** — вспомогательные экраны.

Интерфейс двуязычный (RU/EN), без регистрации и бэкенда — весь профиль хранится локально в браузере.

## Стек

Чистые **HTML5 / CSS3 / JavaScript**, без сборщиков, фреймворков, транспайлеров и бэкенда. Хранение — `localStorage` браузера.

## Архитектура

Каждый файл в `js/` — самостоятельный модуль (IIFE), вешающий себя на `window.Uniora.<имя>`:

| Модуль | Отвечает за |
|---|---|
| `data.js` | демо-датасет: 18 вузов, 6 специальностей, 6 стран, категории достижений, профориентационный квиз, таблица приоритетов по странам. Все пользовательские строки — двуязычные объекты `{ru, en}` |
| `state.js` | слой состояния поверх `localStorage`, `deepMerge` для обратной совместимости схемы профиля при обновлениях |
| `match.js` | детерминированный rule-based алгоритм подбора и диагностики — расчёт запаса по порогам, категоризация Match/Reach/Safety, честная обработка «нет данных». Без вызова LLM |
| `i18n.js` | состояние языка, словарь интерфейса, `t()`/`tf()`, переключение языка перезагружает страницу |
| `common.js` | общие UI-компоненты: навигация, тосты, пустые состояния, сворачиваемые подсказки, бейдж «демо-данные» |
| `profile.js`, `diagnosis.js`, `recommendations.js`, `compare.js`, `roadmap.js`, `favorites.js`, `country-guide.js` | логика конкретных страниц — каждая перерисовывает свой `#...-root` из состояния и данных при любом изменении (прямой императивный рендер без виртуального DOM) |

`css/style.css` — единая дизайн-система на CSS custom properties (цвета, отступы, радиусы, тени).

## Инструкция запуска

Нужен любой статический HTTP-сервер (открытие файлов напрямую через `file://` не подойдёт из-за модульной структуры скриптов):

```bash
npx http-server . -p 8793
```

и открыть `http://127.0.0.1:8793/index.html`.

## Тестовый сценарий

1. На главной нажать «Построить маршрут».
2. Шаг 1–3: выбрать этап обучения, специальность (или пройти мини-квиз), 1–2 страны.
3. Шаг 4: добавить хотя бы одно достижение (например, в «Хакатоны»).
4. Шаг 5: подвинуть слайдеры IELTS/TOEFL/SAT/GPA; один экзамен отметить тумблером «ещё не сдавал(а)» — убедиться, что дальше он показывается как «нет данных», а не как 0.
5. Шаг 6 → «Готово» — попасть на диагностику, увидеть радар-диаграмму и рекомендованный фокус.
6. «Смотреть рекомендации» — увидеть карточки по категориям, подвинуть ползунки в симуляторе «что если».
7. Добавить 2 вуза в сравнение, один — «Сделать целью».
8. Перейти в Roadmap — увидеть автосинхронизированные шаги, добавить свою цель с дедлайном, открыть подсказку «Где брать рекомендательные письма».
9. Сохранить вуз в избранное.
10. Переключить язык кнопкой EN в шапке — убедиться, что весь введённый профиль сохранился и просто отображается на другом языке.

## Источники

Каждый вуз в `data.js` содержит ссылку на его официальный сайт приёмной комиссии — это основной источник. Там, где официальный порог (экзамен, рейтинг, стипендия, дедлайн) не был опубликован источником, команда указала правдоподобную оценку по аналогии со сравнимыми вузами — такие поля явно помечены в комментариях `data.js` и общим бейджем «демо-данные» на страницах с вузами. Датасет собран и курирован вручную для хакатона, не является официальной статистикой вузов.

## AI/API

Во время работы приложения не вызывается ни одна LLM или внешний AI API — подбор и диагностика считаются детерминированным rule-based алгоритмом на чистом JS (`js/match.js`). Из внешних сервисов используются только статические ресурсы: шрифты Google Fonts и картинки флагов стран с flagcdn.com.

Сама разработка велась с помощью AI-ассистента (Claude Code) в паре с командой — итоговые продуктовые и дизайн-решения принимала команда.

## Готовые компоненты

- **Google Fonts** — Space Grotesk, Inter (подключены как CSS-ссылка, без локальной сборки).
- **flagcdn.com** — статичные PNG-иконки флагов стран.
- Диаграммы (радар-диаграмма диагностики, карта-созвездие Roadmap) написаны вручную на inline SVG, без сторонних chart-библиотек. UI-фреймворков и CSS-библиотек не использовано.

## Ограничения условия

- Стоимость обучения и жизни нигде не хранится и не используется как фильтр или критерий подбора — сознательное решение команды.
- Никаких выдуманных «точных» официальных цифр: любая качественная оценка (Match/Reach/Safety, проценты, приоритеты по странам) явно помечена как собственная эвристика команды, а не официальная статистика вуза.
- «Нет данных» никогда не считается как «0»: несданный экзамен — честный пробел в расчётах, а не штраф.
- Без регистрации, логина и серверного хранения — весь профиль живёт только в браузере пользователя.
