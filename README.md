# Uniora

Персональный маршрут поступления в зарубежный вуз — демо-проект для **LOCUS Startup Hackathon 2026**, кейс 02 «Персональный маршрут поступления».

Uniora строит рекомендации и пошаговый план поступления на основе анкеты абитуриента (специальность, страны, экзамены, достижения), а не общего каталога вузов — без вымышленных гарантий и без стоимости обучения как критерия подбора.

## Стек

Чистые **HTML / CSS / JavaScript**, без сборщиков, фреймворков и бэкенда. Все данные пользователя хранятся локально в `localStorage` браузера — сервер не нужен, аккаунта/логина нет.

## Как запустить локально

Нужен любой статический HTTP-сервер (открытие файлов напрямую через `file://` не подойдёт из-за модульной структуры скриптов). Например:

```bash
npx http-server . -p 8793
```

и открыть `http://127.0.0.1:8793/index.html`.

## Структура

```
index.html            — главная
profile.html           — анкета (мастер из 6 шагов)
diagnosis.html          — диагностика профиля
recommendations.html    — подбор вузов (Match / Reach / Safety)
compare.html             — сравнение вузов
roadmap.html              — план поступления (шаги + свои цели)
favorites.html             — избранные вузы
country-guide.html          — сравнение приоритетов по странам

js/data.js       — демо-датасет (вузы, специальности, страны, олимпиады и т.д.)
js/state.js      — слой состояния поверх localStorage
js/match.js      — алгоритм подбора и диагностики (rule-based, без LLM)
js/i18n.js       — переключение языка RU/EN и словарь интерфейса
js/common.js     — общие UI-компоненты (навигация, тосты, подсказки и т.п.)
js/profile.js, diagnosis.js, recommendations.js,
js/compare.js, roadmap.js, favorites.js, country-guide.js
                 — логика соответствующих страниц

css/style.css    — единая дизайн-система
```

## Ключевые принципы

- **Честность вместо красивых цифр.** Проценты совпадения, категории Match/Reach/Safety и «готовность к поступлению» — собственная качественная эвристика команды, явно помеченная как таковая, а не официальная статистика вузов.
- **«Нет данных» ≠ «0».** Если экзамен не сдавался, это честно показывается как отсутствие данных, а не как провальный балл.
- **Без бюджета как фильтра.** Стоимость обучения и жизни сознательно нигде не используется как критерий подбора.
- **RU/EN.** Весь интерфейс и данные — двуязычные, переключаются одной кнопкой в шапке без потери состояния.

## Данные

`js/data.js` — курированный вручную демо-датасет (18 вузов, 6 специальностей, 6 стран). Часть цифр — из открытых источников, часть, где источник не публикует точное значение, — оценка команды по аналогии со сравнимыми вузами. Не является официальной статистикой вузов; актуальность нужно проверять на официальных сайтах перед подачей документов.
